### phase_4   
```
31 CB
```

```func4_1``` 实现了一个递归函数：  
``` c
int func4_1(int n) {
    if(n <= 0)
        return 0;
    if(n == 1)
        return 1;
    return 2 * func4_1(n - 1) + 1;
}
```
计算知通项为 ```func4_1 (n)``` = $2^n-1$   
分析 ```func4_2``` :
``` c
void func4_2(int n, int x, char a, char b, char c, char *out) {
    if (n == 1)
    {
        out[0] = a;
        out[1] = b;
        out[2] = '\0';
        return;
    }
    int f = func4_1(n - 1);
    if (f >= x)
    {
        func4_2(n - 1, x, a, c, b, out);
    }
    else if (f + 1 == x) 
    {
        out[0] = a;
        out[1] = b;
        out[2] = '\0';
    } 
    else 
    {
        func4_2(n - 1, x - f - 1, c, b, a, out);
    }
}
```
分析输入格式  
```
(gdb) x /s 0x322e
0x322e: "%d %2s"
```
输入格式为一个整数和一个长度为 2 的字符串，接下来的代码比较了输入整数和 ```func4_1(5)``` ，因此输入的整数是 $31$ 。然后比较了输入字符串和 ```func4_2(5, 15, 'A', 'C', 'B', out)``` ，运行代码可知输出为 $\text{CB}$ 。

### phase_5  
```
-7 60
```

输入格式为两个整数 $x$ 和 $y$  
```
(gdb) x /s 0x3617
0x3617: "%d %d"
```
代码要求 $x<0$
查询 ```array.0``` 的值：
```
(gdb) x/16dw 0x3280
0x3280 <array.0>:       10      2       14      7
0x3290 <array.0+16>:    8       12      15      11
0x32a0 <array.0+32>:    0       4       1       13
0x32b0 <array.0+48>:    3       9       6       5
```
代码实现了一个循环：$a_n = array.0[a_{n-1}]$ ，其中 $a_0 = x$ & 0xF ，并且要求 $a_9 = 15$ 且 $a_i \neq 15$ $(i < 9)$ 且 $\sum_{i=1}^{9} a_i = y$ ，倒推可知 $a_0 = 9$ ，$y = 60$ ，取 $x = -7$ 。

### secret_phase  
```
33022
```
阅读  ```phase_defused``` 函数发现触发此部分的条件为在第六行输入后面再添加一个字符串，经读取发现 ```Secret word``` 为 ```coding``` 。要求为输入一个长度不超过 20 的字符串 s ，使得 ```func7(s, 0, 0, 0)``` 返回值不为 0 。  
```func7```  检验在一个 8×8 棋盘上，棋子马是否能沿着指定的路径，从起始位置到达 $(4,7)$ 位置，将输入字符串的每个字符的低三位（即 c & 7）当作索引对应马的八个方向，考虑蹩马腿规则。
读取其中棋盘信息：
```
0x61b0 <row0>:  0x00    0x00    0x01    0x00    0x00    0x01    0x00    0x00
0x61c0 <row1>:  0x00    0x00    0x00    0x01    0x00    0x00    0x00    0x01
0x61d0 <row2>:  0x01    0x00    0x01    0x00    0x00    0x01    0x00    0x00
0x61e0 <row3>:  0x01    0x00    0x00    0x00    0x00    0x00    0x00    0x00
0x61f0 <row4>:  0x00    0x01    0x00    0x00    0x01    0x00    0x01    0x00
0x6200 <row5>:  0x01    0x00    0x00    0x01    0x01    0x00    0x00    0x00
0x6210 <row6>:  0x00    0x00    0x00    0x00    0x00    0x01    0x00    0x01
0x6160 <row7>:  0x00    0x01    0x00    0x00    0x00    0x00    0x00    0x00
```
写成 c 风格代码为：
```c
unsigned char board[8][8] = {
    {0, 0, 1, 0, 0, 1, 0, 0}, // row0
    {0, 0, 0, 1, 0, 0, 0, 1}, // row1
    {1, 0, 1, 0, 0, 1, 0, 0}, // row2
    {1, 0, 0, 0, 0, 0, 0, 0}, // row3
    {0, 1, 0, 0, 1, 0, 1, 0}, // row4
    {1, 0, 0, 1, 1, 0, 0, 0}, // row5
    {0, 0, 0, 0, 0, 1, 0, 1}, // row6
    {0, 1, 0, 0, 0, 0, 0, 0}  // row7
};

int func7(char *path, int x, int y, int index)
{
    int dx[] = {-2, -1, 1, 2, 2, 1, -1, -2};
    int dy[] = {1, 2, 2, 1, -1, -2, -2, -1};
    int fdx[] = {-1, 0, 0, 1, 1, 0, 0, -1};
    int fdy[] = {0, 1, 1, 0, 0, -1, -1, 0};

    // 成功条件：到达终点 (4, 7) 且路径正好结束
    if (x == 4 && y == 7)
    {
        return (path[index] == '\0') ? 1 : 0;
    }

    // 失败条件：路径过长或路径提前结束
    if (index >= 19 || path[index] == '\0')
    {
        return 0;
    }

    // 获取当前移动指令
    int move = path[index] & 0x7;

    // 计算马移动后的新坐标
    int new_x = x + dx[move];
    int new_y = y + dy[move];

    // 计算马腿的坐标
    int fx = x + fdx[move];
    int fy = y + fdy[move];

    // 检查新坐标是否越界
    if (new_x < 0 || new_x > 7 || new_y < 0 || new_y > 7)
    {
        return 0;
    }

    // 检查是否蹩马腿
    if (board[fx][fy] == 1)
    {
        return 0;
    }

    // 检查新坐标是否是障碍
    if (board[new_x][new_y] == 1)
    {
        return 0;
    }

    // 检查下一步
    return func7(path, new_x, new_y, index + 1);
}
```  
问题转化为寻找路径，利用 bfs 算法找到一条路径为 {3,3,0,2,2}，对 7 按位与相当于对 8 取余，又  ```'0' = 48 ≡ 0 mod 8``` ，所以直接取字符串 ```"33022"``` 。
