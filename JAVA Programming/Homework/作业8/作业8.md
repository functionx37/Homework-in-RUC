# 网络与多线程综合编程：文件传输

本题目要求设计并实现一个支持多客户端并发访问的文件上传/下载服务器，结合网络编程、多线程技术与进度可视化功能，重点解决以下问题：

* 多客户端并发连接的处理（避免单线程阻塞）；
* 大文件传输的效率优化（多线程分片下载）；
* 客户端与服务端的安全隔离（上传目录隔离、下载目录只读）；
* 传输进度的实时反馈（进度条功能）。

也就是修改完善上次作业。上次作业的内容见下。

1. 服务器端可以接受多个客户上传文件（可以给每个客户单列一个目录用于上传文件），也可接受多个客户从服务器端下载文件（可以单列一个目录，该目录下的文件所有客户均有权限下载，但没权限改动）。（必做）

2. 增加拷贝文件的进度条功能。（可选）

3. 进一步对于大文件下载，在客户端可以采用多线程模式，同时用多个线程下载文件增加文件下载速度。（可选）
