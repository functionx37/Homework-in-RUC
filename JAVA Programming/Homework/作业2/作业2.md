项目目标：

设计并实现一个功能完备的“智能购物篮”系统。购物篮需要能够灵活容纳各种类型的商品（如食品、书籍、电子产品等），并对它们进行统一管理。本练习要求你运用接口定义商品行为，利用多态性处理不同商品，并通过泛型设计一个通用的购物篮。

基础任务：

1.  商品体系构建：

2.  泛型购物篮：实现商品存储、增删、打印明细（含分类统计、找最贵商品）功能。

提示：可以用ArrayList或者T[]来构建泛型购物篮

综合任务：

3.  异常处理与数据验证

比如购物篮空的时候不能删除，满的时候不能增加。

4.  排序与比较

根据商品单价对篮内商品进行排序（升序或降序），并打印排序后的列表，查找并返回所有单价低于pricelimit的商品列表。排序需使用 Comparator实现。

5.  数据持久化（文件I/O）（可选）

将当前购物篮中的所有商品信息（如名称、类型、价格、描述）以易于读取的格式（例如CSV或JSON格式的字符串，此处为简化可用纯文本逐行存储）保存到指定文件。

从指定文件读取数据，重构出购物篮对象并返回。

最终输出与演示要求：

在 main方法中，按顺序演示以下完整流程：

1.  创建一批商品。

2.  将商品加入 GenericBasket（购物篮类）。

3.  演示异常捕获（如尝试移除非法索引）。

4.  对商品按价格排序并打印。

5.  将购物篮状态保存到文件。(可选)

6.  从文件加载另一个购物篮，并打印其明细以验证加载功能。（可选）
