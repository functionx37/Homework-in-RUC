# 多线程作业：

1.	写一个打牌的程序，主要练习多线程间的通讯。生成四个线程，模拟每个player，要求程序能够执行给四个player发牌任务，且控制四个人按顺序出牌的框架（假设每一轮每人出一张牌，比较大小（可先不考虑花色），下一轮大的人先出），每轮出牌后程序给出判断结果，并通知赢家player出牌，进行下一轮，直到所有人都出牌结束。

2.	补充思考题： 试着写例子，理解对静态方法和实例方法加锁的不同之处。试着写程序了解线程死锁的情境。

## 思路和知识补充

`import java.util.concurrent.locks`

打牌思路：用lock的condition

A，B，C，D的设计五个conditionT，conditionA，conditionB，conditionC，conditionD

A，B，C，D最初都等待conditionT，这个是轮次开始的信号。A要等待conditionD唤醒，执行完后唤醒conditionA，B要等待conditonA，唤醒conditionB， C等待conditionB， 唤醒conditionD，D等待conditionC 唤醒conditionA 

ConditionT由另外一个线程控制，表示轮次开始，并指定从谁开始，并等待本轮最后一个线程唤醒。每轮有个计数器，计数到4（计数器有可能发生死锁之类的，可以用原子锁类型），也就是本轮最后一个（可能是ABCD）的时候唤醒表示轮次的线程，但不唤醒它原本应该唤醒的线程，等轮次安排这个线程处理数据后决定唤醒哪一个。

主要的注意点：是如何控制顺序。可以靠唤醒。

以上是让同学们直接利用锁进行实现。

## Card类和发牌类的参考：

```java
class Card implements Comparable<Card>
{
	private char color;
	private int number;
	public char getColor()
	{
		return this.color;
	}
	public int getNumber()
	{
		return this.number;
	}
	public void setCard(char clr,int nmb)
	{
		this.color=clr;
		this.number=nmb;
	}
	public int compareTo (Card o)
	{
		if (this.getColor()> o.getColor())
		{
			return 1;
		}
		else if (this.getColor()< o.getColor())
		{
			return -1;
		}
		else
		{
			if (this.getNumber()> o.getNumber())
			{
				return 1;
			}
			else if (this.getNumber()< o.getNumber())
			{
				return -1;
			}
			else return 0;
		}
	}
}
```

```java
private static class Dealer
	{
		private Card cards[];
		private int index;


		public Dealer() throws NullPointerException
		{
			char[] colors={'C','D','H','S'};
			index=0;
			cards=new Card[52];
			for (int i=0;i<52;i++)
			{
				cards[i]=new Card();
				cards[i].setCard(colors[i/13],i%13+1);
			}
			shuffle();
		}
//可以用collections里面的shuffle()方法
public void swap(int i,int j)
{
	char c=cards[i].getColor();
	int n=cards[i].getNumber();
	cards[i].setCard(cards[j].getColor(),cards[j].getNumber());
	cards[j].setCard(c,n);
}
public void shuffle()
{
	index=0;
	System.out.println("shuffling...");
	Random mRandom = new Random();
	for (int i=cards.length;i>0;i--)
	{
		int rand = mRandom.nextInt(i);
		swap(rand,i-1);
	}
}
public void display()
{
	System.out.println("All Cards Are As Follows: ");
	for (int i=0;i<52;i++)
	{
		System.out.print(cards[i].getColor()+cards[i].getNumber()+" ");
	}
	System.out.println();
}
public synchronized Card getCard()
{
	try{
		if (index==52)
		{
			index=0;
			shuffle();
		}
	}
	catch (Exception ex) {
		ex.printStackTrace();
	} 
	return cards[index++];
}
```
