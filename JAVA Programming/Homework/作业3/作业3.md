# JAVA数据结构———最多变位词查找器

练习说明：练习JAVA数据结构，源代码在课件中下载`datasource.zip`文件，可以利用文件中的RBTreeMap,BSTreeMap、MyHashMap，以及JAVA系统提供的HashMap和TreeMap。

可以学习所给出的源代码，体会这些数据结构的底层逻辑。

两个词表文件：`words.txt`和`dictionary.txt`也在课件上可以下载。这次作业可以只用`dictionary.txt`文件，单词量比较小。

## 1. 目标

开发一个程序，找出具有最多变位词的单词或单词组。

## 2. 问题描述

你需要开发一个命令行 Java 应用程序，用于查找具有最多变位词的单词或单词组。变位词是指使用给定单词的所有字符，但顺序不同或大小写不同的另一个单词。例如，“tea” 和 “eat” 是变位词；“tae” 和 “aet” 只是字符的排列，不是变位词，因为它们不在字典文件中。即使大小写不同，“Tea” 和 “Eat” 仍然是变位词。

### 解析命令行参数
程序需要接收1个命令行参数。如果提供的参数数量不正确，程序将向标准错误输出以下提示信息并退出：

`Usage: java MostAnagramsFinder`

如果命令行参数数量正确，程序将验证字典文件是否存在。如果文件不存在，程序将向标准错误输出以下信息并退出：

`Error: Cannot open file '" + args[0] + "' for input.`

此外，可增加一个参数，表明所使用的数据结构类型，可以比较不同类型的数据结构之间的效率，以及使用起来的方便程度。

### 解析输入文件

选用合适的数据结构完成功能，如二叉树映射，红黑树映射或哈希映射。要求支持运行时可切换所使用的具体数据结构（可以通过命令行参数的形式，比如再增加一个命令行参数）。

字典文件包含所有需要处理的单词列表。字典中不会出现两次完全相同大小写的单词。文件中的单词顺序是随机的，可能已排序也可能未排序。对于文件中的每个单词，将其转换为小写字符，对字符进行排序，然后将键值对插入到映射中。

如果在读取过程中发生 I/O 错误，程序必须向标准错误输出以下信息并退出：

`Error: An I/O error occurred reading '" + args[0] + "'.`

### 显示输出

如果输入文件中没有找到变位词，输出将是字符串字面量：

`No anagrams found.`

如果存在变位词，第一行输出将显示变位词组的数量和变位词计数。有时只有一个最大长度的单词组，但有时会有多个组的长度相同。始终输出：

`Groups: " + groupCount + ", Anagram count: " + anagramCount`

每个组用方括号`[]`包围。组中的单词按词典序排序。这意味着以大写字母开头的单词会出现在以小写字母开头的单词之前。组本身按第一个单词的词典序排序。

输出中不能有任何多余的空白字符（如空格或制表符）。在每行的最后一个可见字符后，光标必须移到下一行。

## 3. 示例输入/输出
对于提供的`dictionary.txt`文件，命令：

`java MostAnagramsFinder dictionary.txt`

输出：

`Groups: 1, Anagram count: 8 [Stael, Tesla, least, slate, stale, steal, tales, teals]`

对于提供的`words.txt`文件，命令：

`java MostAnagramsFinder words.txt`

输出：


所有单词在`[`和`]`之间都在同一行，尽管上面显示为两行。文档宽度不足以容纳所有字符。在组的`]`后输出换行符。

## 补充：

switch的箭头语法，Java12后的新增功能

`case 常量 -> { 语句块 }`

这种表述是为了防止以前switch语法中忘记写break，不会跳出当前情况，会继续向下判断。

```java
public void printTraversal(int type) {
    switch (type) {
        case PREORDER -> {           // 箭头语法            System.out.print("Preorder traversal:       ");
            System.out.println(preorder());
        }
        case INORDER -> {            // 箭头语法
            System.out.print("Inorder traversal:        ");
            System.out.println(inorder());
        }
        case POSTORDER -> {          // 箭头语法
            System.out.print("Postorder traversal:      ");
            System.out.println(postorder());
        }
    }}

Lamda表达式
// 标准形式：(参数) -> { 方法体 }(String name) -> { System.out.println("Hello, " + name); }
// 简化形式（单参数可省略括号，单语句可省略大括号和 return）
name -> System.out.println("Hello, " + name)
// 多参数(a, b) -> a + b
// 带类型推断(int x, int y) -> x * y
```

补充修正后的interface可以有带有方法体的方法。

前面加上修饰词default，这样做的目的是某个方法可以有缺省的方法体，如果需要覆盖时再覆盖，主要是方便编程序简洁，但在一定程度上破坏了原来的强制覆写的规范。
